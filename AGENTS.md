# AGENTS.md

## Cursor Cloud specific instructions

### Overview

Freelance Timer is a Tauri 2 + React + TypeScript desktop time-tracking app backed by Supabase (Postgres + Auth + RLS). For development, the frontend runs in the browser via Vite; the Tauri native shell is optional.

### Running services

| Service | Command | URL |
|---------|---------|-----|
| Vite dev server | `npm run dev` | http://localhost:5173 |
| Local Supabase | `supabase start` (from repo root) | http://127.0.0.1:54321 (API), :54323 (Studio), :54324 (Mailpit) |

### Environment variables

The `.env` file (gitignored) must contain:
```
VITE_SUPABASE_URL=http://127.0.0.1:54321
VITE_SUPABASE_ANON_KEY=<anon key from `supabase status`>
```

When using local Supabase, email confirmation is auto-approved — no need to check Mailpit for signup flows.

### Key commands

- **Install deps:** `npm install`
- **Type-check:** `npx tsc -b`
- **Dev server:** `npm run dev`
- **Production build:** `npm run build`
- **Start local Supabase:** `export PATH="$HOME/.local/share/supabase:$PATH" && supabase start`
- **Stop local Supabase:** `export PATH="$HOME/.local/share/supabase:$PATH" && supabase stop`

### Non-obvious notes

- The Supabase CLI requires both `supabase` and `supabase-go` binaries to be co-located. Install the tarball to `$HOME/.local/share/supabase` and add to PATH, rather than extracting just the `supabase` binary.
- Docker must be running before `supabase start` (it uses Docker containers for Postgres, Auth, etc.).
- Starting Docker in the cloud VM requires `sudo dockerd` with `fuse-overlayfs` storage driver and `iptables-legacy`.
- The app gracefully handles missing Supabase config by showing a "Configure Supabase" informational page instead of crashing.
- Migrations live in `supabase/migrations/` and are automatically applied by `supabase start`.
- No ESLint or Prettier config exists in the repo; only TypeScript type-checking (`tsc -b`) is available for linting.
- The `supabase/config.toml` is generated by `supabase init` and is not committed; run `supabase init` if it's missing before `supabase start`.
